# Install your Cyberpunk GitHub profile

1. Open https://github.com/PainQisGod.
2. Check whether you already have a **public repository named exactly `PainQisGod`**. GitHub only displays a profile README from a public repository whose name exactly matches your username.
3. If it exists, replace its `README.md` and upload the `assets/` folder from this package. If it does not exist, create a public repository named `PainQisGod`, then upload both items.
4. Keep the folder structure exactly as shown:

   ```text
   PainQisGod/
   ├── README.md
   └── assets/
       └── night-city.svg
   ```

5. Commit the changes and refresh your profile.

The animated banner is a self-contained SVG. No build step, server, API key, or GitHub Action is required.

## Personalization notes

- The project list and account details are based on the public profile view available when this package was prepared.
- Edit the tech badges in `README.md` to match the technologies you want to showcase publicly.
- The Cyberpunk-inspired banner is original artwork made for this profile concept; it is not an official Cyberpunk 2077 asset.
