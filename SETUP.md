# PainQ — Night City GitHub Profile

## Install

1. Open `https://github.com/PainQisGod/PainQisGod`.
2. Upload `README.md` to the repository root.
3. Upload the `assets` folder, keeping `night-city.svg` inside it.
4. Commit the changes to the default branch (`main`).
5. Refresh `https://github.com/PainQisGod`.

The expected repository structure is:

```text
PainQisGod/
├── README.md
└── assets/
    └── night-city.svg
```

## Notes

- The banner is a self-contained SVG; no build tools or dependencies are needed.
- SVG animation support can vary across browsers and GitHub's image rendering. If the animation is not shown, the artwork should still display as a static banner.
- GitHub statistics images are served by `github-readme-stats.vercel.app`, a third-party service. They may occasionally be unavailable or rate-limited.
- Edit the About section and technology badges to match the tools you actively use.
