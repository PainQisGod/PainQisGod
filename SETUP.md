# PainQ — Autumn (Hirara) GitHub Profile

## Install

1. Open `https://github.com/PainQisGod/PainQisGod`.
2. Upload `README.md` to the repository root.
3. Upload the `assets` folder, keeping all the SVG files inside it.
4. Commit the changes to the default branch (`main`).
5. Refresh `https://github.com/PainQisGod`.

The files the README uses:

```text
PainQisGod/
├── README.md
└── assets/
    ├── autumn-leaves.svg      # animated hero banner
    ├── section-01-about.svg
    ├── section-02-builds.svg
    ├── section-03-stack.svg
    ├── section-04-signal.svg
    └── footer-autumn.svg
```

## Notes

- The banner and section headers are self-contained SVGs; no build tools needed.
- SVG animation can vary across browsers and GitHub's image rendering. If the falling leaves don't animate, the banner still shows as a static image.
- The stats cards come from `github-readme-stats.vercel.app`, a third-party service. They can occasionally be unavailable or rate-limited.
- Theme colors: crimson `#D33D2B` on dark `#101014`. Keep new badges and cards in the same palette.
- To change the About text or tech badges, edit `README.md` only.
- Old leftovers (`night-city.svg`, and `hirara.jpg` if the banner doesn't embed it) can be deleted from `assets/`.
